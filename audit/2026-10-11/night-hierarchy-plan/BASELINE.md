The font family is Manrope, with bundled regular/medium/semibold/bold/extra-bold files. There is no Thin font assignment in the reviewed settings roles. The user's thin-looking impression is a valid design preference; it is not evidence that the wrong font file is loading.

Important data boundary: Owner Records provides task, reference, actor, state, time and a trailing amount **or quantity**. It does not provide a product name in its list-row model. Cashier Activity likewise lacks a product-name summary field. Style the fields actually available; adding product summaries to those lists is a separate data requirement. Do not parse a formatted currency string to infer meaning. Keep all identifiers, currency, signs, quantities, units, correction/archived states and actor information.

The supporting search inventory (`LIST_SITES.csv`) maps source call sites, not unique screens or confirmed defects. Existing surfaces/insets are retained. Additional unrelated observations belong in LATER.md.
