**Phase 1:** the original batch 1b already named erroneous amount/account, cancellation and genuine returns. The recent B3b/c/d split makes that existing goal executable. Check protected reset paths if administration is used. Provider/Viewer checks may close without changes if already satisfied. No real staff reset or destructive restore as a fixture.

**Phase 5:** select actual shop roles/tasks, PIN/biometric cancellation, Back, haptics, re-entry, keyboard and representative larger text. An omitted broad checkpoint must be disclosed, not reported as an all-green full run. No speculative optimization, dependency upgrades or dormant-code cleanup in release packaging.
